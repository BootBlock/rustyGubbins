# Security

## Telling us about a problem

If you think you've found a security problem in rustyGubbins, please tell us privately rather than
in a public issue. Use GitHub's private reporting:
[report a vulnerability](https://github.com/BootBlock/rustyGubbins/security/advisories/new), or the
**Report a vulnerability** button on the repository's **Security** tab. Only you and the
maintainers can see the report.

It helps to include:

- the version or commit you were using, and your operating system;
- what an attacker could do, and what they'd need first;
- the steps, or a small example, that show it happening.

We'll reply within a week, keep you posted while we work on a fix, and credit you in the advisory
if you'd like us to. Please keep the details to yourself until a fix is out.

## Which versions we fix

rustyGubbins hasn't had a release yet. Until it does, fixes go into the latest code only. Once
releases begin, we'll fix the most recent one.

## What isn't a security problem

A crash or a wrong result is a bug, and a [bug report](https://github.com/BootBlock/rustyGubbins/issues/new?template=bug-report.yml)
is the right place for it, unless someone could use it to reach data or run code they shouldn't.
